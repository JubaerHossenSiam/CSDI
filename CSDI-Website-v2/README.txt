CSDI Website - Design V2 (26 November 2026)

website/
  The full V2 design as plain HTML pages. Open index.html in any browser.
  All menu, footer and button links work between pages.
  Images and the Manrope font are included, so it works offline.
  Pages are responsive: make the browser window narrow to see the phone
  layout. On phones, tap the menu button to open the menu.

source/
  The original design files from the Claude design canvas (.dc.html files
  and canvas.json). Keep these as the backup of V2.

Notes
- This is a design, not the final website. Forms, filters, Load More,
  the lightbox and the FAQ open/close are shown but not built.
- Text marked as dummy (fees, dates, durations, numbers, policies) must be
  confirmed by the client.
